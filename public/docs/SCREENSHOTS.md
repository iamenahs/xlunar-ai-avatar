# Screenshot Guide

To capture screenshots for the README:

1. Run the dev server: `npm run dev`
2. Open http://localhost:3000
3. Capture the following views:

## Required Screenshots

| Filename | Description | Tab |
|----------|-------------|-----|
| `main-interface.png` | Default view with model and Speech tab | Speech |
| `model-selection.png` | Model dropdown showing VRoid Hub models | Model |
| `vrma-animations.png` | VRMA tab showing VRoid Project animations | VRMA |
| `poses-panel.png` | Pose tab with poses, gestures, motions | Pose |
| `motion-sequences.png` | Combos tab showing motion sequences | Combos |
| `scene-panel.png` | Scene tab with backgrounds and cameras | Scene |

## Recommended Screenshots

- Different VRoid Hub models (Hinase, Yukina, Rii, etc.)
- Models with different poses or animations
- Models with different backgrounds

## Image Specifications

- Format: PNG
- Width: ~1200px (will scale in README)
- Capture full browser window for context
